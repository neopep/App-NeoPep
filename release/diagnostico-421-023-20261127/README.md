Nenhuma mensagem é enviada pela recuperação, nenhum reenvio é disparado por ela. Uma recuperação bem-sucedida por grupo na sessão do provider. Não força modo de endereçamento nem contorna restrições de plataforma. A reconstrução normal ocorre em eventual envio posterior autorizado, não durante a recuperação.
