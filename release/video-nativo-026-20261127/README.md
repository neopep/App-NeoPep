# NeoPep Connect 0.2.26 — vídeos nativos
Base Windows 0.2.25 (3823b841a546ec534a3c16059a40f3217fd62f3f). Corrige a regra histórica que enviava MOV e MP4 >16 MiB como documentos.
- MOV e MP4 aceitos hoje (até 25 MiB) são preparados localmente em MP4/H.264/AAC compatível; remux quando elegível, transcode quando necessário. Preserva duração e áudio quando presentes, sem modificar original. Limite conservador de 16 MiB para mídia nativa e 65 segundos de conversão. Se não couber ou converter dentro do prazo, falha antes de transmitir, sem fallback documental. Outros formatos de vídeo ainda não aceitos pelo fluxo de upload precisam ser convertidos antes do upload; nunca devem ser enviados como documento.
- Reutiliza o conversor FFmpeg verificado já previsto, com instalação explícita uma vez na aba Publicar. Não redistribui executável do conversor nem instala silenciosamente. Sem conversor, a publicação de vídeo não ocorre.
- Provider envia somente MP4 nativo por payload video; PDF continua document. Mantém proteção de 421 e não reenvia campanha anterior.
- Alteração de compatibilidade SQL após build aprovado: versões anteriores preservadas para não-vídeo; somente 0.2.26 com capacidade native_video_v1 pode claim/start vídeo; futuras versões exigem atualização da allowlist e capacidade nativa. Falha de conversão separada de 421 e de entrega incerta. Nenhuma campanha é reenviada ou alterada retroativamente.
- Alterações web candidatas: seletor Documento apenas PDF/TXT; Vídeo MP4/MOV, texto de conversão nativa e falha. Reconciliar com commit real publicado antes de deploy web; não publicar branch Windows inteira.
- Testes automáticos de contrato e conversão, inclusive MOV real com áudio quando FFmpeg estiver disponível na CI. Homologação real no WhatsApp exige mensagem legítima futura, sem novos testes repetidos no Mundo Pep.
