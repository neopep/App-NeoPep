# Runtime privado candidato — Pacote 01
Decisão: preparar um host Linux existente (inclusive VM/WSL2 dedicado se homologado), Docker rootless, gateway HTTP em 127.0.0.1:8788 e Cloudflare Tunnel + VPC Service apontando exclusivamente a esse endereço. Workers VPC gratuito durante beta: https://developers.cloudflare.com/workers-vpc/platform/pricing/ . Sem mudança de plano ou recurso provisionado. Containers gerenciados exigem plano pago: https://developers.cloudflare.com/containers/ . Não usar túnel público, VPC Network amplo ou endereço de Produção.
O gateway exige segredo aleatório de 32 bytes em hexadecimal (NEO_VALIDATOR_SECRET no host, NEO_CONNECT_AI_MEDIA_VALIDATOR_SECRET no Worker), configurado por operador em canal seguro; nunca no GitHub/chat. Binding NEO_CONNECT_AI_MEDIA_VALIDATOR deve ser VPC Service dedicado. O Worker usa URL interna HTTP dentro do túnel; conexão host local loopback. Não publicar rota pública. O scanner recebe os mesmos bytes do parser, roda sem rede, sem capacidades, sem root, filesystem read-only e limites de memória/CPU/PIDs; base ClamAV montada somente leitura. Atualizar assinaturas por processo separado, rejeitar desatualizadas. Nenhum arquivo persiste no host intencionalmente.
Gates obrigatórios: aprovar base por digest e versões instaladas (Pillow/pypdf/FFmpeg/ClamAV), auditar vulnerabilidades, construir imagem local e fixar ID, confirmar Docker rootless e limites efetivos, scanner com assinaturas oficiais atuais, testes de formatos reais e EICAR (arquivo de teste inofensivo), falhas/timeout/limites, benchmark dentro de 15s incluindo startup do scanner; se não couber, redesenhar para scanner persistente isolado. Limitar saída do subprocesso e tráfego concorrente na homologação do host. Só então configurar NEO_VALIDATOR_HOST_HOMOLOGATED=1 e segredo. O CI testa o contrato com mocks, não executa Docker/ClamAV reais. O host não está disponível ao conector atual. O CLI offline anterior continua fail-closed. Não ativar MEDIA/DRAFTS ou executar migrações até autorização e leitura real Teste.
