# NeoPep Connect AI — decisão candidata de hospedagem e próxima entrega
Data: 26/11/2026. Status: decisão de produto aprovada pelo usuário: Cloudflare-first, sem dependência de computador para a nova integração. Validação técnica ainda pendente; sem provisionamento, sem deploy, sem gastos autorizados.
## Escolha
Cloudflare Workers como hospedagem inicial escolhida para o servidor MCP e processamento da nova integração; Supabase permanece fonte de verdade. Vercel é contingência técnica, não alvo da V1. Nenhuma nova tarefa deve depender do Windows na V1; o envio WhatsApp existente via Connect Windows permanece inalterado. O frontend continua nos dois projetos Vercel existentes. Não migrar o App nem Pages/Analytics. Domínios propostos connect.neopep.com.br e connect-teste.neopep.com.br, ainda sem DNS/Worker. Usar o mesmo contrato de ferramentas e uma camada de serviço independente de runtime para manter a opção de mudar de hospedagem sem reescrever a lógica de campanhas.
## Extensibilidade futura
Separar transporte MCP, serviço de campanhas, storage e processamento de tarefas. Definir contrato versionado de tarefas com IDs estáveis, estado, idempotência, resultado e capacidades do executor; manter o executor cloud como único ativo na V1. Prever registro de executores e seleção cloud/local por capacidade, com autorização explícita, revogação e isolamento de ambientes. Não implementar serviço Windows, tunnel, fila local ou UI de executor nesta etapa; não introduzir dependência prematura. Só adicionar fila assíncrona cloud se os testes mostrarem necessidade. Se o processamento pesado exceder limites, apresentar alternativas de processamento cloud e custos para aprovação, sem ativar Windows ou contratar plano automaticamente.
## Evidências
- Cloudflare Workers Free: 100.000 requisições/dia, 10 ms CPU por invocação, 128 MB memória, 50 subrequests por invocação; corpo HTTP até 100 MB na zona Free. I/O não equivale a tempo CPU. Não confundir limite de corpo com capacidade de processar imagens. https://developers.cloudflare.com/workers/platform/limits/
- Workers Paid: preço-base US$5/mês, uso incluído e cobranças excedentes; confirmar plano efetivo e custos de dependências/armazenamento antes de ativar. https://developers.cloudflare.com/workers/platform/pricing/
- Vercel: MCP suportado com mcp-handler; 4,5 MB de corpo por padrão; beta 20 MiB requer plano/configuração compatíveis; Hobby 100 deploys/24h por owner. Já tivemos bloqueio real 402. Hobby limitado a uso pessoal não comercial; reavaliar plano aplicável ao NeoPep comercial independentemente desta decisão. https://vercel.com/docs/mcp/deploy-mcp-servers-to-vercel ; https://vercel.com/docs/functions/limitations ; https://vercel.com/docs/limits ; https://vercel.com/docs/limits/fair-use-guidelines
- Cloudflare MCP: https://developers.cloudflare.com/agents/model-context-protocol/ . O plano da zona Free Website foi confirmado; Billing Read indisponível, plano Workers não confirmado. Não presumir custo zero.
