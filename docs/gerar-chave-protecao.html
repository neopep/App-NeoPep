Proteção das integrações

Este arquivo gera uma chave no seu navegador, sem enviar dados pela internet. Ela protege as chaves das APIs salvas pelo painel.

Salve em Supabase → Edge Functions → Secrets, com o nome NEO_AI_ENCRYPTION_KEY. Guarde também no seu gerenciador de senhas. Não envie no chat. Ela é diferente da chave da OpenAI, Gemini ou Claude.

Não substitua uma chave já configurada: isso impede ler as credenciais existentes e exige cadastrá-las novamente.
